# Student Record Manager

A Python-based Student Record Management project that demonstrates the practical implementation of Data Structures and Algorithms (DSA).

The project uses a Singly Linked List to manage student records and implements Merge Sort and Binary Search for efficient sorting and searching operations.

## ✨ Features

- Store student roll numbers, names, and marks.
- Insert new student records.
- Delete student records using roll numbers.
- Update student marks.
- Search student records using Linear Search.
- Sort students by marks in descending order.
- Sort students by roll number.
- Search student records using Binary Search.
- Prevent duplicate roll numbers.
- Display student records in tabular format.
- Visualize the Top 5 Scorers using a bar chart.

## 🛠️ Technologies Used

- Python 3
- Jupyter Notebook
- Matplotlib

## 🧠 Data Structures & Algorithms

| Concept | Implementation |
|---|---|
| Data Structure | Singly Linked List |
